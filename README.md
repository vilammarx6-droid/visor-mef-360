# 🔎 Plataforma de Auditoría Ciudadana (MEF & Contraloría)

Esta plataforma es un motor de análisis masivo impulsado por DuckDB que cruza las bases de datos de ejecución financiera del MEF con los reportes de inspección física de la Contraloría (INFOBRAS).

Si quieres saber cómo subir esta plataforma a internet (Streamlit Cloud o Hugging Face Spaces), lee el archivo `INSTRUCCIONES_DE_DESPLIEGUE.md`.

## Para correrlo en tu computadora:

1. Abre tu terminal.
2. Instala los requerimientos: `pip install -r requirements.txt`
3. Inicia la aplicación: `streamlit run app.py`
